# Calorie AI - бесплатная тестовая версия

Эта версия использует Gemini API, у которого есть бесплатный уровень для ряда моделей и ограничений. Бесплатный доступ и квоты могут меняться и зависят от региона/аккаунта. Не предназначено для коммерческого публичного запуска.

## Что есть
- Telegram-бот с /start, /help, /today и /goal
- распознавание фотографии через Gemini vision
- примерные калории, белки, жиры, углеводы и вес
- дневник питания SQLite
- лимит 10 фото в сутки
- webhook-режим для развёртывания как бесплатный web service

## 1. Создать ключи с телефона
1. В Telegram открой @BotFather, отправь /newbot и создай бота.
2. Сохрани токен BotFather приватно.
3. Открой https://aistudio.google.com/apikey и создай Gemini API key. Обычно можно начать на бесплатном уровне; если Google попросит оплату или недоступно в регионе, не добавляй платёжные данные - сообщи об этом, подберём другой вариант.
4. Никогда не вставляй токены в публичный репозиторий и не отправляй их в чат.

## 2. Бесплатный Render через GitHub
Render free web service не предназначен для постоянного production-бота; сервис может засыпать, а локальный SQLite-файл не является постоянным хранилищем. Для короткого теста это приемлемо.

1. Создай приватный репозиторий на https://github.com/new.
2. Добавь файлы проекта в репозиторий, кроме .env. Не загружай ключи.
3. Открой https://dashboard.render.com/ и создай New > Blueprint, выбрав репозиторий с render.yaml. Если Blueprint неудобен на телефоне, создай Web Service вручную.
4. После создания сервиса открой Environment и добавь:
   - TELEGRAM_BOT_TOKEN = токен от BotFather
   - GEMINI_API_KEY = ключ из Google AI Studio
   - WEBHOOK_BASE_URL = публичный URL сервиса, например https://имя-сервиса.onrender.com
   - WEBHOOK_SECRET = случайная строка из латинских букв и цифр
5. Нажми Deploy/Manual Deploy и дождись успешного запуска.
6. Открой URL сервиса в браузере телефона: должен появиться текст `Calorie AI test bot is running`.
7. Открой своего бота в Telegram, нажми Start и отправь фото.

## Важно
- При первой настройке WEBHOOK_BASE_URL должен быть равен реальному URL Render-сервиса.
- Render Free может засыпать после периода без входящих HTTP-запросов, а локальная SQLite база может теряться при перезапуске. Это тестовый стенд, не production.
- Квоты Gemini Free Tier ограничены и могут меняться. Не обещай пользователям постоянную бесплатность.
- Фото не позволяет точно определить массу порции, масло и скрытые ингредиенты. Результаты приблизительные.
- Платежи, Premium, редактирование блюд, удаление данных, резервные копии и полноценная защита от злоупотреблений пока не реализованы.
